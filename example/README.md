# Flutter UI Debug - Example App

This is a comprehensive demo application that showcases all features of the `flutter_ui_debug` library.

## Running the App

To run this example app on your device:

```bash
cd example
flutter run
```

The app will launch with debug mode enabled by default, allowing you to test all debug features.

## Features

The app includes demo pages for:

- **Animation Basics** - Simple animation with basic debug overlays
- **Multi-Phase** - Multi-phase animation with phase contract debugging
- **Transforms** - Complex transform animations (translation, scale, rotation)
- **Constraints** - Layout constraint visualization and rebuild detection
- **Performance** - Multiple animations for performance testing
- **Gestures** - Gesture recognition and hit test visualization

## Using the Debug Control Panel

1. Tap the **settings icon** in the app bar, or
2. Tap the **floating action button** (tune icon)

The control panel allows you to:
- Toggle individual debug capabilities on/off
- Use quick presets:
  - **All On** - Enable all debug features
  - **All Off** - Disable all debug features
  - **Animation** - Enable animation-related features
  - **Layout** - Enable layout-related features
  - **Performance** - Enable performance monitoring features

## Navigation

- Use the **drawer menu** (hamburger icon) to switch between demo pages
- Each demo page showcases different debug features
- The Frame Rate Monitor appears in the top-right when enabled

## Testing Features

1. Navigate to a demo page
2. Open the debug control panel
3. Enable the capabilities you want to test
4. Observe the debug overlays and visualizations
5. Try different combinations of features

## Tips

- Start with the "Animation Basics" demo to see basic features
- Use the "Multi-Phase" demo to test phase contract debugging
- Enable "Frame Rate Monitor" to see performance metrics
- Try the "Performance" demo with multiple animations to stress test

Enjoy testing all the debug features!
