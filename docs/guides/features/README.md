## Adding Feature Documentation

When documenting a new feature:
1. Create a new markdown file named after the feature
2. Include:
   - Overview and use cases
   - Setup instructions
   - Code examples
   - Configuration options
   - Common patterns
   - Troubleshooting tips
3. Link from this README
