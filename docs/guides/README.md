# User Guides

This directory contains user-facing documentation for `flutter_ui_debug`.

## Structure

- **[Getting Started](getting-started/)** - Installation and basic usage
- **[Features](features/)** - Detailed guides for each feature

## Adding New Guides

When adding a new feature guide:
1. Create a new markdown file in the appropriate subdirectory
2. Follow the existing guide format
3. Include code examples
4. Link from the main README
5. Update the table of contents if applicable
