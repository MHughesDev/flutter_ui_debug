# Code Examples

This directory contains code examples demonstrating how to use `flutter_ui_debug`.

## Structure

- **[Basic Examples](basic/)** - Simple, focused examples for individual features
- **[Advanced Examples](advanced/)** - Complex, real-world usage patterns

## Example Categories

### Basic Examples
- Enabling debug mode
- Using individual debug widgets
- Simple animation debugging
- Basic phase contract setup

### Advanced Examples
- Multi-phase animation debugging
- Complex transform debugging
- Performance optimization workflows
- Integration with existing apps

## Contributing Examples

When adding examples:
1. Create a self-contained, runnable example
2. Include comments explaining key concepts
3. Add a brief description at the top
4. Test that the example compiles and runs
5. Follow the existing example format
